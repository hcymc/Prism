# 评测

`eval/` 下 13 个脚本，每个回答一个具体问题。全部默认读 `$PRISM_HOME` 下的 `blocks.pt` 与
`runs/v3_30class/best.pt`，也可以 `--checkpoint` 指定别的。

```bash
export PRISM_HOME=/path/to/prism-data
python eval/eval_per_class.py
```

## 清单

| 脚本 | 回答什么问题 |
| --- | --- |
| `eval_suite.py` | 一次跑完「短/中/长 × 多个来源」的汇总表，出 JSON |
| `eval_bylen.py` | 同一批文档只截前 N 字，命中率随长度怎么变 |
| `eval_pad.py` | 短文本**重复补齐**到 512 到底能救回多少（和直接判对比） |
| `eval_classes.py` | 每类取相同篇数（类均衡）的总体命中率 |
| `eval_per_class.py` | 每个类别各自多少分，找出最差的几类 |
| `eval_long.py` | 2000 字长文：切块平均 vs 只看前 512 字 |
| `eval_llm_text.py` | 外部模型（DeepSeek）写的文章，检验换一批文本掉多少 |
| `eval_unseen.py` | 手写句子抽查，看没见过的表述 |
| `eval_punct.py` | 全角/半角标点的控制变量实验 |
| `one_text.py` | 单段文字的完整 31 维分布（调试用，最常用的一个） |
| `compare_ckpts.py` | 两份权重同一批样本对账 |
| `diag_unk.py` | 输入里有多少字落在词表外（`<unk>` 比例） |
| `diag_unk_chars.py` | 具体是哪些字不在词表里 |

## 三个必须分清的指标

评测结果如果混着报，数字会互相骗人：

1. **自然分布**（按验证集真实比例抽 2000 篇）= 88.45%。
   大类文档多，而大类恰好更好分，所以这个数偏高。
2. **类均衡**（每类 20 篇共 600 篇）= 85.2%。
   这个更接近「每类都不许放弃」的真实水平，**对外报这个**。
3. **单类召回**：航空航天、计算机编程 100%；计算机_通信 **50%**、其他制造/科技/石油化工 60%、
   电力能源 65%。差的那几个是类目边界重叠，不是模型笨。

## 常用结论（v3 实测）

- **长度是最大变量**：30 字 44.4% → 80 字 51.1% → 150 字 56.7% → 300 字 72.2% → 512 字 82.2%
- **补齐很关键**：前 30 字直接判 29.2%，重复补齐到 512 后 62.5%（信息一个字没多，只是长度对了）
- **全角标点只影响置信度**：命中率变化在噪声内，置信度三组一致低 0.03~0.06。
  已经统一在 `src/textproc.py` 做归一化
- **换一批文本掉 20 个点**：同类语料 85%，DeepSeek 写的 150 篇只有 64%

## 写评测脚本的约定

- 别用文件大小当指标，用命中率 / 置信 / 熵这些真数
- 比较两个模型时，样本必须完全相同（同一批 id、同一长度策略）
- 报数字时说明样本量：240 篇时一个标准误约 3 个点，差 2 个点不叫改善
